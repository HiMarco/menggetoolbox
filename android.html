Android UI 设计规范

以 360dp 为唯一手机主设计画板宽度的团队设计规范，适用于 MasterGo、Figma 与 Android 开发交付。基于 Material Design 3 原则，结合中文业务 App 建立统一的设计 Token、组件、页面模板和验收标准。

02

间距系统

统一使用 Spacing Token，避免 7、13、19、27dp 等随机间距。常用组合：图标与文字 8dp，卡片内边距 16dp，模块间距 24dp，页面分区 32–40dp。

Android 系统适配规范

系统约束：不能把状态栏固定成 24dp、底部手势区固定成 24dp。在 Android 15 且 target SDK ≥35 的应用中，Edge-to-Edge 默认强制生效，需使用 WindowInsets 处理系统栏、挖孔和软键盘。
区域实施规则
状态栏根据系统 Insets 获取安全区域
底部手势 / 三键兼容实际系统导航区域
刘海 / 挖孔避免按钮与文字被遮挡
软键盘使用 IME Insets 调整可见内容
横屏按可用窗口宽度重新布局

响应式窗口适配

可用宽度设计策略
< 360dp内容优先；允许文本换行与紧凑适配
360dp严格对照设计基准
361–599dp边距和组件规则一致，内容自适应
600–839dp按业务考虑分栏
≥840dp宽屏布局或设置内容最大宽度

图片处理

Banner固定宽高比，宽度自适应
缩略图固定比例，按约定裁切
头像1:1，圆形或指定圆角
插画等比缩放，不拉伸
背景图明确裁切策略和视觉焦点
图标优先矢量图
图片占位提前保留尺寸以避免布局跳动
